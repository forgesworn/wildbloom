# Support

Use [GitHub Issues](https://github.com/forgesworn/wildbloom/issues/new/choose)
for non-sensitive installation, interoperability and usage questions.  Include
the exact Wildbloom commit or URL, operating system and browser version, and a
minimal reproduction made with disposable data.

Public support is best effort.  Wildbloom is an open-source project, not a
hosted storage provider, and the repository owners cannot recover a lost file,
recovery key or signing key.

Never put a private key, `nsec`, recovery key, unpublished event, private file,
live credential, personal data or private endpoint into an issue.  Report a
security-sensitive defect through
[private vulnerability reporting](https://github.com/forgesworn/wildbloom/security/advisories/new)
instead.

Wildbloom Node has its own
[issue tracker](https://github.com/forgesworn/wildbloom-node/issues) for desktop
installation, bundled Tor and replication problems.
